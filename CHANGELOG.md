## [1.0.0] - 2026-11-05

### Добавлено

- Главный экран: сводка по двум компаниям (выручка, расходы, остаток, НЗ), ленточные карточки
  каждой компании, наличные в кассе, график выручки за 14 дней, последние записи,
  переключатель периода (этот месяц / прошлый месяц / 30 дней / всё время).
- Экран «Запись дня»: две крупные кнопки выбора компании («Затон Рыбака», «Арт Фокус»),
  выбор даты с переходом по дням, поля «Сумма по терминалу», «Остаток наличных в кассе»,
  «Положено в НЗ», динамический список расходов с комментариями, комментарий к дню,
  живой блок «Итоги дня», сохранение, обновление и удаление записи.
- Экран «История»: фильтры по компании, периоду и датам, поиск по комментариям, сводка по выборке,
  раскрывающийся список расходов, редактирование и удаление записей с подтверждением.
- Экспорт отчёта в CSV для Excel (UTF-8 BOM, разделитель «;», десятичная запятая) по текущей
  выборке и резервное копирование данных в JSON с восстановлением.
- Автоматический пересчёт всех сводных показателей после каждой записи, правки и удаления.
- Тёмная тема в стиле X: Dim (#15202B) и Lights out (#000000), акцент #1D9BF0,
  скруглённые карточки с обводкой #2F3336, кнопки-пилюли, линейные SVG-иконки,
  левое меню-сайдбар с иконками.
- Локальное хранение в JSON: атомарная запись, автобэкап, поддержка portable-режима
  (данные рядом с exe) и восстановление после повреждения файла.
- Сборка установщика NSIS и portable-версии для Windows через electron-builder.
- GitHub Actions: CI (типы, 39 тестов, сборка) и Release по тегу `v*` с публикацией .exe
  и заметками из CHANGELOG.
- Скрипты `npm run bump` (инкремент версии + changelog) и генерация иконки приложения.
